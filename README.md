# CISI-ACF
Repository for Roblox's Cheat-Inspector Script Injection Anti-Cheat Framework.

CISI ACF(Cheat-Inspector Script Injection Anti-Cheat Framework) is an Anti-Cheat framework for Roblox which allows developers to create client-sided Anti-Cheats.
It contains many defense layers to ensure the integrity of the Anti-Cheat. The benefit of CISI is its ability to detect cheats which original Anti-Cheats cannot.
This does not mean that one must choose one or the other; CISI is, in fact, meant to be used alongside server-sided Anti-Cheat for maximum protection.

It is recommended you start [here](https://github.com/league-ld/CISI-ACF/blob/main/How%20to%20use.md).
